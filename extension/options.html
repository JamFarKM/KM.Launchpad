Pull requests in Launchpad

Azure DevOps pull request pages offer a link here — from Slack, Jira, email, anywhere.

Where your browser reaches Launchpad. Nothing is sent anywhere — the address is only used to build the link you click.

Turn this off and Azure DevOps looks exactly as it did. Nothing is redirected either way — the link is an offer, so the page you asked for is still the page you get.
