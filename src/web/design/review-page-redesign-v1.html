Review page — proposed changes
  • Vote hierarchy. Approve is solid; the two middle votes are outline; Reject is outline but tints red on hover, behind a divider. Icons added so the four are scannable without reading.
  • Auto-inline for one-sided files. A file that is 100% additions or deletions opens in Inline with an “all additions · inline” chip explaining why. The toggle still overrides, and the override sticks for the session.
  • Collapsible side panels. ◧ / ◨ buttons in the diff toolbar collapse the PR list and the file tree, so a wide side-by-side diff can use the full window.
  • Diff colour recalibrated. Row tint is now faint and a 2px gutter stripe carries the identification, so an all-added file is no longer a solid slab. The line-number gutter stays neutral on changed rows, which fixes its contrast.
  • Syntax palette with no green and no red. The diff tint owns those hues, so nothing in the code competes with add/remove. Comments are neutral grey — the biggest legibility win on a mostly-commented diff.
  • Word-level diff on modified line pairs (see lines 204/205 of MigrationService.cs).
  • Folder grouping in the file tree, collapsible, with the path on the folder row — so the two 001_CreateDB.sql files are no longer ambiguous and filenames rarely need truncating.
  • Viewed checkboxes + “3 of 7 viewed” progress, so you can keep your place in a long review.
  • File-type badges off status colours — A/M/D now use aqua/violet/slate, keeping green and red for the diff body only (spec invariant A2).
  • Collapsed-lines row is one row spanning both panes, with a real chevron icon and expand-up / expand-all / expand-down.
  • Composer stays an overlay as you preferred — but made deliberate: elevation, a pointer to its line, and a scrim over the lines it covers so it reads as floating rather than broken. Comment is now a real primary button and Cancel is a proper outline button.
  • Wrap + code size in the toolbar ⋯ menu; long lines no longer clip silently.
  • One empty state, not two contradictory ones.
  • STARRED merged into the picker row, reclaiming a full row of vertical space.
  • PR list gains search plus per-row comment count, file count, author and draft/conflict flags.
  • Not included, per your call: per-file +/− counts in the tree. Project/repository pickers left as they are, with only a title added — the duplicate “Account” was a genuine name collision, not a labelling bug.
