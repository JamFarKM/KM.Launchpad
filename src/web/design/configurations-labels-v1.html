Configurations — one row per key, labels stacked in the detail pane
  • The middle pane lists each key once. A key carrying three labels was three rows; it is now one. Flip the toggle above to compare — AccaBonus goes from 5 rows to 3.
  • The Label column becomes a label count (3 labels), plus a DIFFERS marker when those labels don't all agree. Drift becomes scannable from the list without opening anything.
  • Value preview comes from the baseline — the no-label value, which is what the app resolves when no label is requested.
  • The detail pane stacks one collapsible section per label. The baseline sits first and is marked BASELINE; named labels follow, each tagged SAME or DIFFERS against it.
  • Differing lines are marked inside the JSON with a faint tint and a gutter stripe — the same grammar as the Review page's diff rows, so the two pages read as one system.
  • A summary strip above the sections names which labels differ, with jump chips. Sections that match the baseline start collapsed; ones that differ start open, so the page opens on what you need to look at.
  • Drift is never colour alone — every marker carries a word (SAME / DIFFERS) and an icon (invariant A4).
  • Amber, not red. A label differing from the baseline is normal and expected, not a failure — so it uses --status-warn, and green/red stay with pipeline status (invariant A2).
  • Detail pane widened to 520px from 470 — it now holds several values rather than one.
