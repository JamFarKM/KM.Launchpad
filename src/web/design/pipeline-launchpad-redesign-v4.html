v4 changes
  • Card separation back to hairlines — cards have no border or gap, just a shared divider. It now works in both directions, so when a shelf narrows and cards stack, the divider becomes horizontal automatically.
  • Rail and tint are both kept — the toggle now offers Rail / Tint / Both / None so you can ship it as a theme preference.
  • ✕ and ⋯ swapped — ✕ sits top-right next to the status glyph (same visual weight, red on hover), ⋯ moved down to the footer where ✕ used to be.
  • Glyph shape toggle — square vs circle, so you can judge the swap now that ✕ is its neighbour rather than ⋯.
  • Texture — a faint dot grid on the board canvas, and a 45° hatch on the slim "+ add pipeline" rail at the end of each shelf. Toggle above; see the note in my reply on where texture does and doesn't work.
  • Configurations colour — environment identity colour (Dev/Test/Prod) carried on the endpoint strip, value-type badges coloured by type, key counts on a single-hue magnitude ramp, sticky column headers, richer JSON highlighting.
